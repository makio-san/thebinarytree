## Linux namespaces
- year: 2002
- kind: component
- era: modern
- parent: cgroups
- creators: Al Viro
- wikipedia: Linux namespaces
- summary: A kernel feature that gives a group of processes its own view of mounts, process ids, network interfaces and users. It began with the mount namespace in Linux 2.4.19 in 2002, borrowed from Plan 9, and with cgroups it is what a container is made of.
- sources: https://en.wikipedia.org/wiki/Linux_namespaces
- confidence: high

## Python Package Index (PyPI)
- year: 2003
- kind: concept
- era: modern
- parent: python
- creators: none (Python Software Foundation)
- wikipedia: Python Package Index
- summary: The official repository of third party Python packages, proposed in PEP 301 in 2002 and launched in 2003. pip installs from it by default and it holds well over half a million projects.
- sources: https://en.wikipedia.org/wiki/Python_Package_Index
- confidence: high
