## Strassen algorithm
- year: 1969
- kind: concept
- era: theory
- parent: complexity-theory
- creators: Volker Strassen
- wikipedia: Strassen algorithm
- summary: Volker Strassen showed in 1969 that two matrices can be multiplied in fewer steps than the schoolbook method needs. It proved the obvious algorithm was not the best one and opened the long search for the true cost of matrix multiplication.
- sources: https://en.wikipedia.org/wiki/Strassen_algorithm, https://en.wikipedia.org/wiki/Volker_Strassen
- confidence: high
- found via: https://scottaaronson.blog/?p=10362
- note: the lead for this was Scott Aaronson's post of 25 November (https://scottaaronson.blog/?p=10379), which the list does not link; the 24 November post linked in the list is on the same blog and thread. `cooley-tukey-fft` sits beside `complexity-theory` and uses era `theory` for 1965, so the same era is used here.
