## Network address translation (NAT)
- year: 1994
- kind: concept
- era: network
- parent: tcp-ip
- creators: none
- wikipedia: Network address translation
- summary: Rewriting addresses in packets as they pass a router, so a whole private network can share one public IPv4 address. RFC 1631 called it a short term fix for address depletion in 1994, and it became how most homes reach the Internet.
- sources: https://en.wikipedia.org/wiki/Network_address_translation
- confidence: high

## CockroachDB

- parent: newsql
- creators: Spencer Kimball, Peter Mattis, Ben Darnell

## NVLink

- kind: component
- era: modern
- parent: nvidia-v100

## Quantum error correction
- year: 1995
- kind: concept
- era: modern
- parent: quantum
- creators: Peter Shor
- wikipedia: Quantum error correction
- summary: Spreading one logical qubit across many physical qubits so noise can be detected and undone without measuring the information itself. Shor's nine qubit code of 1995 was the first, and every serious quantum computer since is judged by how well it does this.
- sources: https://en.wikipedia.org/wiki/Quantum_error_correction
- confidence: high

## Trapped-ion quantum computer
- year: 1995
- kind: concept
- era: modern
- parent: quantum
- creators: Ignacio Cirac, Peter Zoller
- wikipedia: Trapped-ion quantum computer
- summary: Qubits held as single charged atoms suspended by electric fields and steered with lasers. Cirac and Zoller proposed the first scheme for a quantum logic gate with trapped ions in 1995; the approach now gives the most accurate gates of any platform.
- sources: https://en.wikipedia.org/wiki/Trapped-ion_quantum_computer
- confidence: high

## CPU cache
- year: 1968
- kind: component
- era: integrated
- parent: system-360
- creators: none
- wikipedia: CPU cache
- summary: A small fast memory beside the processor that keeps copies of recently used data, hiding how slow main memory is. Early examples were the Atlas 2 and the IBM System/360 Model 85 of 1968; today the cache is often the largest part of a CPU by area.
- sources: https://en.wikipedia.org/wiki/CPU_cache
- confidence: medium

## Ray tracing
- year: 1968
- kind: concept
- era: integrated
- parent: graphics
- creators: Arthur Appel
- wikipedia: Ray tracing (graphics)
- summary: Making an image by following rays of light between the eye, the objects and the lights. Arthur Appel published the first computer use for shaded pictures in 1968; since 2018 graphics cards trace rays in real time.
- sources: https://en.wikipedia.org/wiki/Ray_tracing_(graphics)
- confidence: high

## Kolmogorov complexity
- year: 1963
- kind: concept
- era: theory
- parent: information-theory
- creators: Andrey Kolmogorov
- wikipedia: Kolmogorov complexity
- summary: The information in a string measured as the length of the shortest program that prints it. Kolmogorov published on it in 1963 and Solomonoff and Chaitin reached it independently; no single program can compute it for every string.
- sources: https://en.wikipedia.org/wiki/Kolmogorov_complexity
- confidence: high
