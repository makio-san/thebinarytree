## Rowhammer
- year: 2014
- kind: concept
- era: modern
- parent: dram
- creators: none
- wikipedia: Row hammer
- summary: A flaw of dense DRAM in which reading the same memory rows many times flips bits in neighbouring rows. Research presented in June 2014 named the effect, and in March 2015 Google's Project Zero showed working privilege escalation exploits based on it.
- sources: https://en.wikipedia.org/wiki/Row_hammer
- confidence: high

- year: 2009
- kind: concept
- era: modern
- parent: rsa
- creators: Craig Gentry
- wikipedia: Homomorphic encryption
- summary: Encryption that lets a computer calculate on data without decrypting it. The problem was posed in 1978, within a year of RSA, and Craig Gentry described the first plausible fully homomorphic scheme in 2009 using lattice-based cryptography.
