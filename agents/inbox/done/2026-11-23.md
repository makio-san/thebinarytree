## Hamming code
- year: 1950
- kind: concept
- era: tube
- parent: information-theory
- creators: Richard Hamming
- wikipedia: Hamming code
- summary: The first practical error correcting codes. Hamming wanted punched card readers to fix their own single bit errors, and Hamming(7,4) does it by adding three parity bits to four bits of data.
- sources: https://en.wikipedia.org/wiki/Hamming_code
- confidence: high

## Reed-Solomon error correction
- year: 1960
- kind: concept
- era: transistor
- parent: information-theory (or the new Hamming code node)
- creators: Irving S. Reed, Gustave Solomon
- wikipedia: Reed-Solomon error correction (redirect; the article title uses an en dash)
- summary: Codes that work on symbols rather than single bits, so they can repair whole bursts of damage. They are inside CDs, DVDs, Blu-ray, QR codes, DSL, satellite links and RAID 6.
- sources: https://en.wikipedia.org/wiki/Reed%E2%80%93Solomon_error_correction
- confidence: high

## Cooley-Tukey FFT algorithm
- year: 1965
- kind: concept
- era: integrated
- parent: theory
- creators: James Cooley, John Tukey
- wikipedia: Cooley-Tukey FFT algorithm (redirect; the article title uses an en dash)
- summary: The most common fast Fourier transform. Splitting a discrete Fourier transform into smaller ones recursively cuts the work to N log N, which made digital signal processing practical.
- sources: https://en.wikipedia.org/wiki/Cooley%E2%80%93Tukey_FFT_algorithm
- confidence: high

## Monte Carlo method
- year: 1946
- kind: concept
- era: tube
- parent: eniac
- creators: Stanislaw Ulam, John von Neumann, Nicholas Metropolis (named it)
- wikipedia: Monte Carlo method
- summary: Using repeated random sampling to solve problems too hard to solve exactly. Ulam had the idea at Los Alamos in 1946, and the first fully automated Monte Carlo runs were on ENIAC in spring 1948.
- sources: https://en.wikipedia.org/wiki/Monte_Carlo_method
- confidence: high

## Dijkstra's algorithm
- year: 1956
- kind: concept
- era: tube
- parent: theory
- creators: Edsger W. Dijkstra
- wikipedia: Dijkstra's algorithm
- summary: Finds the shortest paths from one node to every other in a weighted graph. Conceived in 1956 and published in 1959, it still routes packets in protocols such as IS-IS and OSPF.
- sources: https://en.wikipedia.org/wiki/Dijkstra%27s_algorithm
- confidence: high

## Quicksort
- year: 1959
- kind: concept
- era: transistor
- parent: theory
- creators: Tony Hoare
- wikipedia: Quicksort
- summary: A divide and conquer sort that partitions around a pivot and recurses. Hoare developed it in 1959 and published it in 1961, and it is still one of the most used sorting algorithms.
- sources: https://en.wikipedia.org/wiki/Quicksort
- confidence: high

## PageRank
- year: 1996
- kind: concept
- era: modern
- parent: search-engines
- creators: Larry Page, Sergey Brin
- wikipedia: PageRank
- summary: Ranks a web page by the number and quality of links pointing to it. Page and Brin developed it at Stanford in 1996 and described it in their 1998 paper on the Google prototype.
- sources: https://en.wikipedia.org/wiki/PageRank
- confidence: high

## Bourne shell
- year: 1979
- kind: language
- era: network
- parent: research-unix-v6
- creators: Stephen Bourne
- wikipedia: Bourne shell
- summary: The default shell of Version 7 Unix and the basis of POSIX sh syntax. Work began at Bell Labs in 1976, and /bin/sh on Unix-like systems still points to it or a compatible shell such as Bash.
- sources: https://en.wikipedia.org/wiki/Bourne_shell
- confidence: high

## File Allocation Table (FAT)
- year: 1977
- kind: concept
- era: personal
- parent: floppy-disk
- creators: Marc McDonald (after discussions with Bill Gates)
- wikipedia: File Allocation Table
- summary: A simple file system first written for floppy disks in Microsoft's Standalone Disk BASIC and later the default for DOS and Windows 9x. Grown through FAT12, FAT16, FAT32 and exFAT, it still formats most USB drives and SD cards.
- sources: https://en.wikipedia.org/wiki/File_Allocation_Table
- confidence: high

## NTFS
- year: 1993
- kind: concept
- era: modern
- parent: windows-nt (or the new FAT node)
- creators: none
- wikipedia: NTFS
- summary: Microsoft's journaling file system, default since Windows NT 3.1. It added access control lists, encryption, compression and shadow copies that FAT lacked.
- sources: https://en.wikipedia.org/wiki/NTFS
- confidence: high

## Creeper
- year: 1971
- kind: concept
- era: network
- parent: systems-security
- creators: Bob Thomas (BBN), later version by Ray Tomlinson
- wikipedia: Creeper and Reaper
- summary: The first computer worm, an experiment that moved between TENEX machines on the ARPANET. Reaper, written to remove it, is counted as the first antivirus program.
- sources: https://en.wikipedia.org/wiki/Creeper_and_Reaper
- confidence: high

## WannaCry ransomware attack
- year: 2017
- kind: concept
- era: modern
- parent: systems-security
- creators: none
- wikipedia: WannaCry ransomware attack
- summary: A May 2017 worm that encrypted Windows machines worldwide and demanded bitcoin. It spread through EternalBlue, an NSA exploit leaked a month earlier, mostly on systems that had not applied an existing patch.

- confidence: high
