# Scout inbox, 2026-11-20

Third pass. Yesterday's two runs covered headline launches from 2019 to 2026, the deep learning toolchain and security plumbing. This pass goes after durable gaps in other places: open social protocols, internet and storage plumbing, data systems, Linux internals, PC gaming, e-readers and the two big model families not yet in the tree.

## ActivityPub
- year: 2018
- kind: network
- era: modern
- parent: web-platforms
- creators: Christine Lemmer-Webber, Jessica Tallon, Erin Shepherd, Amy Guy, Evan Prodromou
- wikipedia: ActivityPub
- summary: The W3C standard for federated social networking, published as a Recommendation on 23 January 2018. Independent servers exchange posts and follows with it, and it is what holds the Fediverse together.
- sources: https://www.w3.org/TR/activitypub/, https://en.wikipedia.org/wiki/ActivityPub
- confidence: high

## Mastodon
- year: 2016
- kind: network
- era: modern
- parent: activitypub (queued above; if it is not added, twitter)
- creators: Eugen Rochko
- wikipedia: Mastodon (social network)
- summary: Free software for running your own microblogging server, first released in March 2016. Servers talk to each other over ActivityPub, so users on different servers can follow one another.
- sources: https://en.wikipedia.org/wiki/Mastodon_(social_network), https://github.com/mastodon/mastodon/releases/tag/v0.1.0
- confidence: high

## Bluesky and the AT Protocol
- year: 2023
- kind: network
- era: modern
- parent: twitter
- creators: none (began in 2019 as a research project funded by Twitter under Jack Dorsey; now Bluesky Social PBC)
- wikipedia: Bluesky
- summary: A microblogging service built as the reference app for the AT Protocol, which lets users keep their identity and social graph when they move between servers. It opened as an invite only beta in February 2023 and to everyone on 6 February 2024.
- sources: https://en.wikipedia.org/wiki/Bluesky, https://en.wikipedia.org/wiki/AT_Protocol, https://bsky.social/about/blog/02-06-2024-join-bluesky
- confidence: high

## IPv6
- year: 1995
- kind: network
- era: network
- parent: tcp-ip
- creators: Steve Deering, Robert Hinden
- wikipedia: IPv6
- summary: The successor to IPv4, first specified in RFC 1883 in December 1995, with 128 bit addresses so the internet would not run out. It became a full Internet Standard in 2017.
- sources: https://www.rfc-editor.org/rfc/rfc1883.html, https://en.wikipedia.org/wiki/IPv6
- confidence: high

## High Bandwidth Memory
- year: 2013
- kind: component
- era: modern
- parent: dram
- creators: none (sources credit SK Hynix, AMD and Samsung)
- wikipedia: High Bandwidth Memory
- summary: DRAM dies stacked on top of each other and placed next to the processor, giving far more bandwidth than memory on a board. JEDEC adopted it in October 2013, AMD's Fiji GPUs shipped it first in 2015, and today it feeds every large AI accelerator.
- sources: https://en.wikipedia.org/wiki/High_Bandwidth_Memory
- confidence: medium

## NVM Express
- year: 2011
- kind: component
- era: modern
- parent: ssd
- creators: none (an industry working group led by Intel)
- wikipedia: NVM Express
- summary: A storage interface designed for flash rather than spinning disks, with many deep command queues over PCI Express. Version 1.0 came out on 1 March 2011 and it is now how most SSDs connect.
- sources: https://en.wikipedia.org/wiki/NVM_Express, https://nvmexpress.org/
- confidence: high

## Apache Kafka
- year: 2011
- kind: concept
- era: modern
- parent: analytics
- creators: none (sources credit LinkedIn; Jay Kreps, Neha Narkhede and Jun Rao are commonly named, but I did not confirm this in a source I opened)
- wikipedia: Apache Kafka
- summary: A distributed log for streams of events, open sourced by LinkedIn in January 2011 and later an Apache project. It made processing data as it arrives, not in nightly batches, a normal part of company infrastructure.
- sources: https://en.wikipedia.org/wiki/Apache_Kafka, https://kafka.apache.org/
- confidence: high

## DuckDB
- year: 2019
- kind: concept
- era: modern
- parent: column-store
- creators: Mark Raasveldt, Hannes Mühleisen
- wikipedia: DuckDB
- summary: An embedded column store for analytical queries, built at CWI in Amsterdam and first released in 2019. It does for analysis what SQLite did for small transactional databases: a whole database in one library, no server needed.
- sources: https://duckdb.org/why_duckdb, https://en.wikipedia.org/wiki/DuckDB
- confidence: high

## Julia
- year: 2012
- kind: language
- era: modern
- parent: scripting
- creators: Jeff Bezanson, Stefan Karpinski, Viral B. Shah, Alan Edelman
- wikipedia: Julia (programming language)
- summary: A dynamic language for numerical and scientific computing, announced on 14 February 2012. Multiple dispatch and just in time compilation let it read like Python and run close to C speed.
- sources: https://julialang.org/blog/2012/02/why-we-created-julia/, https://en.wikipedia.org/wiki/Julia_(programming_language)
- confidence: high

## systemd
- year: 2010
- kind: os
- era: modern
- parent: linux
- creators: Lennart Poettering (Kay Sievers is often named as co-author; not confirmed in a source I opened)
- wikipedia: Systemd
- summary: The init system and service manager that runs as process 1 on almost every Linux distribution since about 2015. It replaced the old shell script startup and brought logging, devices and logins under one suite.
- sources: https://en.wikipedia.org/wiki/Systemd, https://systemd.io/
- confidence: high

## Wayland
- year: 2008
- kind: os
- era: modern
- parent: linux
- creators: Kristian Høgsberg
- wikipedia: Wayland (protocol)
- summary: A display protocol in which the compositor is the display server, started in 2008 as a simpler and more secure replacement for the X Window System. Major Linux desktops now use it by default.
- sources: https://wayland.freedesktop.org/, https://en.wikipedia.org/wiki/Wayland_(protocol)
- confidence: high

## Steam
- year: 2003
- kind: concept
- era: modern
- parent: games
- creators: none (Valve)
- wikipedia: Steam (service)
- summary: Valve's game client, which left beta on 12 September 2003 to deliver updates for Valve's own games and began selling other studios' games in 2005. It made digital distribution the normal way to buy PC games.
- sources: https://en.wikipedia.org/wiki/Steam_(service), https://www.steamdeck.com/
- confidence: high

## Amazon Kindle
- year: 2007
- kind: device
- era: mobile
- parent: handhelds
- creators: none (Amazon's Lab126)
- wikipedia: Amazon Kindle
- summary: An E Ink reader that went on sale on 19 November 2007 and downloaded books over its own free wireless connection. It turned e-books from a niche into a mass market.
- sources: https://press.aboutamazon.com/2007/11/introducing-amazon-kindle, https://en.wikipedia.org/wiki/Amazon_Kindle
- confidence: high

## Claude
- year: 2023
- kind: concept
- era: modern
- parent: llm
- creators: none (Anthropic)
- wikipedia: Claude (AI)
- summary: Anthropic's family of large language models, first released on 14 March 2023 and trained with a written constitution. Later versions became widely used for writing software and running agents.
- sources: https://www.anthropic.com/news/introducing-claude, https://en.wikipedia.org/wiki/Claude_(AI)
- confidence: high

## Gemini
- year: 2023
- kind: concept
- era: modern
- parent: llm
- creators: none (Google DeepMind)
- wikipedia: Gemini (language model)
- summary: Google DeepMind's multimodal model family, announced on 6 December 2023 as the successor to PaLM 2. It was built to take text, images, audio and video from the start.
- sources: https://blog.google/technology/ai/google-gemini-ai/, https://en.wikipedia.org/wiki/Gemini_(language_model)
- confidence: high
