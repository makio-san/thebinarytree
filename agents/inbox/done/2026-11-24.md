## Mach (kernel)
- year: 1985
- kind: os
- era: network
- parent: unix
- creators: Richard Rashid, Avie Tevanian
- wikipedia: Mach (kernel)
- summary: A kernel built at Carnegie Mellon as a replacement for the BSD Unix kernel, and one of the earliest microkernels. Its descendants sit inside GNU Hurd and the XNU kernel of macOS and iOS.
- sources: https://en.wikipedia.org/wiki/Mach_(kernel)
- confidence: high

- era: modern
- parent: mach (add Mach from this inbox first; otherwise minix)

## Internet Relay Chat (IRC)
- year: 1988
- kind: network
- era: network
- parent: bbs
- creators: Jarkko Oikarinen
- wikipedia: IRC
- summary: A text chat system built around channels, written at the University of Oulu in August 1988 to replace a chat program on a bulletin board system. It spread to other Finnish and then American universities.

## SHRDLU
- year: 1968
- kind: concept
- era: integrated
- parent: ai
- creators: Terry Winograd
- wikipedia: SHRDLU
- summary: An early natural language understanding program written at MIT between 1968 and 1970, in which a user talked to the computer about moving blocks in a simple virtual world. It ran in Micro Planner and Lisp on a PDP-6.
- sources: https://en.wikipedia.org/wiki/SHRDLU
- confidence: high

## Itanium

- kind: processor
- era: modern
- parent: intel-line
- creators: none (Hewlett-Packard and Intel)

## OLED
- year: 1987
- kind: component
- era: micro
- parent: displays
- creators: Ching Wan Tang, Steven Van Slyke
- wikipedia: OLED
- summary: A light emitting diode whose emissive layer is an organic film, first made practical at Eastman Kodak in 1987. Each pixel makes its own light, so OLED screens need no backlight, unlike LCDs.
- sources: https://en.wikipedia.org/wiki/OLED
- confidence: high

## Sendmail
- year: 1983
- kind: concept
- era: network
- parent: email
- creators: Eric Allman
- wikipedia: Sendmail
- summary: A mail routing program Allman derived from his earlier delivermail at UC Berkeley. It shipped with 4.1c BSD in 1983, the first BSD with TCP/IP, and carried much of the early Internet's mail.
- sources: https://en.wikipedia.org/wiki/Sendmail
- confidence: high

## grep
- year: 1973
- kind: concept
- era: network
- parent: ed
- creators: Ken Thompson
- wikipedia: Grep
- summary: A command that prints lines matching a regular expression. Thompson took the regular expression code out of ed to make it, and it first shipped in Version 4 Unix. McIlroy called it the prototypical software tool.
- sources: https://en.wikipedia.org/wiki/Grep
- confidence: high

## Open Shortest Path First (OSPF)
- year: 1989
- kind: network
- era: network
- parent: tcp-ip
- creators: none (IETF; John Moy appears only in the references)
- wikipedia: Open Shortest Path First
- summary: A link state routing protocol for IP networks inside one autonomous system, first standardised in 1989 as RFC 1131. Each router builds a map of the network and computes shortest paths over it.
- sources: https://en.wikipedia.org/wiki/Open_Shortest_Path_First
- confidence: high

- era: tube
- parent: input-devices
