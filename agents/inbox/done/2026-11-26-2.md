## Universal Chiplet Interconnect Express (UCIe)
- year: 2022
- kind: concept
- era: modern
- parent: pci-express
- creators: none
- wikipedia: UCIe
- summary: An open standard for connecting chiplets from different makers inside one package. Version 1.0 was released on 2 March 2022 by a consortium that includes AMD, Arm, Intel, Qualcomm, Samsung and TSMC, and version 4.0 followed on 12 November 2026.
- sources: https://en.wikipedia.org/wiki/UCIe
- confidence: high

## Valkey
- year: 2024
- kind: concept
- era: modern
- parent: redis
- creators: none
- wikipedia: Valkey
- summary: An open source in-memory key-value database that began as a fork of Redis. Its first release came on 28 March 2024 under a BSD licence, and large cloud providers including AWS, Google Cloud and Oracle support it.
- sources: https://en.wikipedia.org/wiki/Valkey
- confidence: high

## JPEG XL
- year: 2021
- kind: concept
- era: modern
- parent: jpeg
- creators: none
- wikipedia: JPEG XL
- summary: An image format with both lossy and lossless modes, developed by the Joint Photographic Experts Group, Google and Cloudinary and defined by ISO/IEC 18181. It grew out of Google's PIK and Cloudinary's FUIF proposals, and its file format was standardized on 13 October 2021.
- sources: https://en.wikipedia.org/wiki/JPEG_XL
- confidence: medium

## InterPlanetary File System (IPFS)
- year: 2015
- kind: network
- era: modern
- parent: bittorrent
- creators: Juan Benet
- wikipedia: InterPlanetary File System
- summary: A peer-to-peer network that finds files by a hash of their content rather than by the server that holds them, using a distributed hash table. Juan Benet created it and an alpha version launched in February 2015.
- sources: https://en.wikipedia.org/wiki/InterPlanetary_File_System
- confidence: high

## Tree-sitter
- year: 2018
- kind: concept
- era: modern
- parent: yacc
- creators: Max Brunsfeld
- wikipedia: Tree-sitter (parser generator)
- summary: A parser generator and incremental parsing library that keeps a syntax tree up to date while code is being edited. Max Brunsfeld wrote it at GitHub for the Atom editor, where it was first released in 2018, and Emacs, Neovim, Zed and Helix now build on it.
- sources: https://en.wikipedia.org/wiki/Tree-sitter_(parser_generator)
- confidence: high

## Apache Arrow
- year: 2016
- kind: concept
- era: modern
- parent: parquet
- creators: none
- wikipedia: Apache Arrow
- summary: A standard column-oriented format for data held in memory, so that analytic tools in different languages can share tables without converting them. It was first released on 10 October 2016.
- sources: https://en.wikipedia.org/wiki/Apache_Arrow
- confidence: high

- parent: column-store

- confidence: high

## LevelDB
- year: 2011
- kind: concept
- era: modern
- parent: lsm-tree
- creators: Jeff Dean, Sanjay Ghemawat
- wikipedia: LevelDB
- summary: An open source on-disk key-value store that Jeff Dean and Sanjay Ghemawat wrote at Google from early 2011, following the design of the Bigtable tablet stack. Chrome uses it for IndexedDB and Bitcoin Core stores blockchain metadata in it.
- sources: https://en.wikipedia.org/wiki/LevelDB
- confidence: medium

## Google File System
- year: 2003
- kind: concept
- era: modern
- parent: analytics
- creators: Ghemawat, Gobioff and Leung (surnames as the article cites the 2003 paper)
- wikipedia: Google File System
- summary: Google's distributed file system for very large files on clusters of commodity hardware, with each chunk replicated three times by default. It was described in a paper at SOSP 2003 and replaced inside Google by Colossus in 2010.
- sources: https://en.wikipedia.org/wiki/Google_File_System , https://static.googleusercontent.com/media/research.google.com/en//archive/gfs-sosp2003.pdf (cited there, not opened)
- confidence: medium

## Skip list
- year: 1989
- kind: concept
- era: personal
- parent: b-tree
- creators: William Pugh
- wikipedia: Skip list
- summary: A sorted linked structure with layers of shortcut links chosen at random, which gives logarithmic search and insertion on average without rebalancing. William Pugh first described it in 1989.
- sources: https://en.wikipedia.org/wiki/Skip_list
- confidence: high

## Simplex algorithm
- year: 1947
- kind: concept
- era: theory
- parent: theory
- creators: George Dantzig
- wikipedia: Simplex algorithm
- summary: George Dantzig's method for solving linear programs, which grew out of his planning work for the US Army Air Force. He arrived at it in 1947 after adding an objective function to his formulation.
- sources: https://en.wikipedia.org/wiki/Simplex_algorithm
- confidence: high

## Hash table
- year: 1953
- kind: concept
- era: theory
- parent: theory
- creators: Hans Peter Luhn
- wikipedia: Hash table
- summary: A data structure that maps keys to values by computing an index into an array of slots, so a lookup takes about the same time however many items are stored. Hans Peter Luhn described hashing with chaining in an internal IBM memorandum in January 1953.
- sources: https://en.wikipedia.org/wiki/Hash_table
- confidence: high

## Linked list
- year: 1956
- kind: concept
- era: theory
- parent: theory
- creators: Allen Newell, Cliff Shaw, Herbert A. Simon
- wikipedia: Linked list
- summary: A sequence of elements in which each one points to the next, so items can be inserted or removed without moving the rest. Allen Newell, Cliff Shaw and Herbert Simon developed it in 1955 and 1956 as the main data structure of their Information Processing Language.
- sources: https://en.wikipedia.org/wiki/Linked_list
- confidence: high
