## cgroups
- year: 2007
- kind: component
- era: modern
- parent: linux
- creators: Paul Menage, Rohit Seth
- wikipedia: Cgroups
- summary: The Linux kernel feature that limits and isolates CPU, memory and I/O for groups of processes. Started at Google in 2006 as process containers, renamed control groups in late 2007, and the base layer of Docker-style containers.

- parent: linux
