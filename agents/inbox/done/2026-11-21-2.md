## Telnet
- year: 1969
- kind: network
- era: network
- parent: arpanet
- creators: Steve Carr
- wikipedia: Telnet
- summary: The first way to log in to a remote computer over ARPANET, proposed in RFC 15 in September 1969 and standardised as RFC 854 in 1983. It sent everything, passwords included, in plain text, which is why SSH replaced it.
- sources: https://www.rfc-editor.org/rfc/rfc15.json, https://www.rfc-editor.org/rfc/rfc854.json, https://en.wikipedia.org/wiki/Telnet
- confidence: high

## Simple Mail Transfer Protocol (SMTP)
- year: 1982
- kind: network
- era: network
- parent: email
- creators: Jon Postel
- wikipedia: Simple Mail Transfer Protocol
- summary: The protocol mail servers still use to hand messages to each other, specified by Jon Postel in RFC 821 in August 1982. It built on the mail exchange ARPANET had used since 1971.
- sources: https://www.rfc-editor.org/rfc/rfc821.json, https://en.wikipedia.org/wiki/Simple_Mail_Transfer_Protocol
- confidence: high

## Internet Message Access Protocol (IMAP)
- year: 1986
- kind: network
- era: network
- parent: email
- creators: Mark Crispin
- wikipedia: Internet Message Access Protocol
- summary: Mark Crispin designed it in 1986 so mail could stay on the server and be managed from several clients, where POP only downloaded it. Version 2 was published as RFC 1064 in 1988, and every modern mail client speaks it.
- sources: https://www.rfc-editor.org/rfc/rfc1064.json, https://en.wikipedia.org/wiki/Internet_Message_Access_Protocol
- confidence: high

## Gopher
- year: 1991
- kind: network
- era: network
- parent: tcp-ip
- creators: Mark McCahill, Farhad Anklesaria, Paul Lindner, Daniel Torrey, Bob Alberti
- wikipedia: Gopher (protocol)
- summary: A menu driven system for finding and fetching documents across the internet, released at the University of Minnesota in 1991. It spread faster than the early web until the university announced licence fees in 1993.
- sources: https://www.rfc-editor.org/rfc/rfc1436.json, https://en.wikipedia.org/wiki/Gopher_(protocol)
- confidence: high

## Network Time Protocol (NTP)
- year: 1985
- kind: network
- era: network
- parent: tcp-ip
- creators: David L. Mills
- wikipedia: Network Time Protocol
- summary: David Mills's protocol for keeping computer clocks in step over a network, published as RFC 958 in 1985 and still in use. It is one of the oldest internet protocols that never went away.
- sources: https://www.rfc-editor.org/rfc/rfc958.json, https://en.wikipedia.org/wiki/Network_Time_Protocol
- confidence: high

## OAuth
- year: 2007
- kind: concept
- era: modern
- parent: http-1-1 (fallback: systems-security)
- creators: Blaine Cook, Chris Messina, Larry Halff, David Recordon, Eran Hammer-Lahav
- wikipedia: OAuth
- summary: A way to let one site act on your account at another without handing over your password. It began at Twitter in 2006, OAuth Core 1.0 came out in October 2007, and OAuth 2.0 became RFC 6749 in 2012.
- sources: https://oauth.net/about/introduction/, https://www.rfc-editor.org/rfc/rfc5849.json, https://www.rfc-editor.org/rfc/rfc6749.json, https://en.wikipedia.org/wiki/OAuth
- confidence: high

- kind: language
- era: personal
- parent: fortran
- creators: Cleve Moler, Jack Little, Steve Bangert
- wikipedia: MATLAB

## LaTeX
- year: 1984
- kind: language
- era: micro
- parent: tex
- creators: Leslie Lamport
- wikipedia: LaTeX
- summary: Leslie Lamport's macros on top of TeX, written at SRI International, which let authors mark up structure while TeX handles layout. It is how most mathematics and computer science papers are still written.
- sources: https://en.wikipedia.org/wiki/LaTeX
- confidence: high

## Long short-term memory (LSTM)
- year: 1997
- kind: concept
- era: modern
- parent: backpropagation
- creators: Sepp Hochreiter, Jürgen Schmidhuber
- wikipedia: Long short-term memory
- summary: A recurrent network with gated memory cells that can carry information across thousands of steps, published in Neural Computation in 1997. It powered speech recognition and machine translation until transformers took over.
- sources: https://en.wikipedia.org/wiki/Long_short-term_memory
- confidence: high

## Stuxnet
- year: 2010
- kind: concept
- era: modern
- parent: systems-security
- creators: none
- wikipedia: Stuxnet
- summary: A worm uncovered in June 2010 that reprogrammed industrial controllers to damage uranium centrifuges in Iran, using four zero day flaws. It is the first widely known cyberweapon aimed at physical machinery.
- sources: https://en.wikipedia.org/wiki/Stuxnet
- confidence: high

## Heartbleed
- year: 2014
- kind: concept
- era: modern
- parent: tls
- creators: Neel Mehta, Codenomicon
- wikipedia: Heartbleed
- summary: A missing bounds check in OpenSSL's TLS heartbeat code that let anyone read server memory, disclosed and fixed on 7 April 2014. It showed how much of the internet rested on one underfunded library.
- sources: https://heartbleed.com/, https://en.wikipedia.org/wiki/Heartbleed
- confidence: high
