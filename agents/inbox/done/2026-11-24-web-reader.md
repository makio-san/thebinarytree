Candidates named in this week's reading list that the tree lacks. Each name was searched in `src/data` and in the open inboxes first, and each fact below comes from the Wikipedia article or the project's own site, not from the post that led to it.

## Ladybird
- year: 2022
- kind: concept
- era: modern
- parent: mozilla-firefox
- creators: Andreas Kling
- wikipedia: Ladybird (web browser)
- summary: An open source web browser with its own engine, not based on Chromium, Gecko or WebKit. It began in 2019 as part of SerenityOS, became a standalone project in 2022, and its first public alpha came out in 2026.
- sources: https://en.wikipedia.org/wiki/Ladybird_(web_browser), https://ladybird.org/posts/alpha/
- confidence: medium
- found via: https://ladybird.org/posts/alpha/
- note: the parent is a placeholder for the browser lineage; Ladybird descends from no existing engine, so the curator may prefer to hang it under the browsers' common ancestor (mosaic) instead.

## Microsoft Exchange Server
- year: 1996
- kind: concept
- era: modern
- parent: email
- creators: none
- wikipedia: Microsoft Exchange Server
- summary: Microsoft's mail and calendaring server, first released on 2 April 1996 as Exchange Server 4.0, the successor to Microsoft Mail. It talks to Outlook over its own MAPI protocol and to other mail servers over SMTP.
- sources: https://en.wikipedia.org/wiki/Microsoft_Exchange_Server
- confidence: high
- found via: https://stalw.art/blog/microsoft-exchange-replacement/

## Web 2.0
- year: 2004
- kind: concept
- era: modern
- parent: web
- creators: Darcy DiNucci, Tim O'Reilly, Dale Dougherty
- wikipedia: Web 2.0
- summary: The name for the shift to websites built on what their users contribute. Darcy DiNucci coined the term in 1999, and Tim O'Reilly and Dale Dougherty made it popular at the first Web 2.0 Conference in 2004.
- sources: https://en.wikipedia.org/wiki/Web_2.0
- confidence: medium
- found via: https://www.oreilly.com/radar/what-happened-to-silicon-valley/
