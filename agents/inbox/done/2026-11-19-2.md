# Scout inbox, 2026-11-19 (second run)

Second pass of the day. This morning's run covered headline launches from 2019 to 2026. This pass looks for durable gaps under existing nodes: the deep learning toolchain, Linux and web security plumbing, chip manufacturing and virtual reality.

## PyTorch
- year: 2016
- kind: concept
- era: modern
- parent: alexnet
- creators: Adam Paszke, Sam Gross, Soumith Chintala, Gregory Chanan
- wikipedia: PyTorch
- summary: Meta's open source deep learning library for Python, built around eager tensors and automatic differentiation. It became the default framework for research and for most large language models.
- sources: https://en.wikipedia.org/wiki/PyTorch, https://arxiv.org/abs/1912.01703, https://github.com/pytorch/pytorch/releases/tag/v0.1.1
- confidence: high

## TensorFlow
- year: 2015
- kind: concept
- era: modern
- parent: alexnet
- creators: none (sources credit the Google Brain team; the 2016 whitepaper lists Martín Abadi first among 40 authors)
- wikipedia: TensorFlow
- summary: Google Brain's machine learning library, released as open source in November 2015 as the successor to its internal DistBelief system. It made large scale neural network training available to everyone.
- sources: https://en.wikipedia.org/wiki/TensorFlow, https://arxiv.org/abs/1603.04467
- confidence: high

## Project Jupyter
- year: 2014
- kind: concept
- era: modern
- parent: python
- creators: Fernando Pérez, Brian Granger
- wikipedia: Project Jupyter
- summary: Interactive notebooks that mix code, results and prose, spun off from IPython in 2014 to serve Julia, Python and R. The notebook became the standard working surface of data science.
- sources: https://en.wikipedia.org/wiki/Project_Jupyter, https://jupyter.org/about
- confidence: high

## ResNet
- year: 2015
- kind: concept
- era: modern
- parent: alexnet
- creators: Kaiming He, Xiangyu Zhang, Shaoqing Ren, Jian Sun
- wikipedia: Residual neural network
- summary: Residual connections let networks with hundreds of layers train, and won ImageNet in 2015. The same skip connection sits inside every transformer.
- sources: https://en.wikipedia.org/wiki/Residual_neural_network, https://arxiv.org/abs/1512.03385
- confidence: high

## Generative Adversarial Networks
- year: 2014
- kind: concept
- era: modern
- parent: backpropagation
- creators: Ian Goodfellow
- wikipedia: Generative adversarial network
- summary: Two networks trained against each other, one generating samples and one judging them. The first generative model that produced convincing synthetic images.
- sources: https://en.wikipedia.org/wiki/Generative_adversarial_network, https://arxiv.org/abs/1406.2661
- confidence: high

## Llama
- year: 2023
- kind: concept
- era: modern
- parent: llm
- creators: none (Meta AI; the paper lists Hugo Touvron first among 14 authors)
- wikipedia: Llama (language model)
- summary: Meta's family of large language models whose weights were released, first to researchers in February 2023 and then under licenses allowing commercial use. It started the open weight model ecosystem.
- sources: https://en.wikipedia.org/wiki/Llama_(language_model), https://arxiv.org/abs/2302.13971
- confidence: high

## DeepSeek-R1
- year: 2025
- kind: concept
- era: modern
- parent: openai-o1
- creators: none (DeepSeek-AI, a team of about 200)
- wikipedia: DeepSeek (chatbot)
- summary: An open weight reasoning model trained largely with reinforcement learning, released in January 2025. It matched closed reasoning models at a fraction of the reported cost and briefly knocked NVIDIA's market value.
- sources: https://en.wikipedia.org/wiki/DeepSeek, https://en.wikipedia.org/wiki/DeepSeek_(chatbot), https://arxiv.org/abs/2501.12948
- confidence: high

## TLS 1.3
- year: 2018
- kind: concept
- era: modern
- parent: tls
- creators: Eric Rescorla
- wikipedia: Transport Layer Security
- summary: The 2018 rewrite of TLS (RFC 8446) that cut the handshake to one round trip and removed old, weak ciphers. It is the version QUIC and HTTP/3 are built on.
- sources: https://www.rfc-editor.org/rfc/rfc8446.html, https://en.wikipedia.org/wiki/Transport_Layer_Security
- confidence: high

## Let's Encrypt
- year: 2016
- kind: concept
- era: modern
- parent: tls
- creators: none (Internet Security Research Group, founded by EFF, Mozilla, the University of Michigan, Akamai and Cisco)
- wikipedia: Let's Encrypt
- summary: A free, automated certificate authority that left beta in April 2016. It made HTTPS the default for the whole web and is now the largest certificate authority in the world.
- sources: https://en.wikipedia.org/wiki/Let%27s_Encrypt
- confidence: high

## WireGuard
- year: 2015
- kind: network
- era: modern
- parent: chacha20
- creators: Jason A. Donenfeld
- wikipedia: WireGuard
- summary: A small, fast VPN protocol built on Curve25519 and ChaCha20 with Poly1305, merged into Linux 5.6 in 2020. It replaced IPsec and OpenVPN in many products.
- sources: https://en.wikipedia.org/wiki/WireGuard, https://www.wireguard.com/
- confidence: high

## eBPF
- year: 2014
- kind: concept
- era: modern
- parent: linux
- creators: Alexei Starovoitov, Daniel Borkmann
- wikipedia: EBPF
- summary: Safe, verified programs that run inside the Linux kernel without kernel modules, exposed through the bpf system call in Linux 3.18. It now powers networking, tracing and security tools across the cloud.
- sources: https://en.wikipedia.org/wiki/EBPF, https://ebpf.io/what-is-ebpf/
- confidence: high

## FinFET
- year: 2011
- kind: component
- era: modern
- parent: mosfet
- creators: Digh Hisamoto, Chenming Hu
- wikipedia: Fin field-effect transistor
- summary: A transistor whose channel stands up as a fin with the gate wrapped around it. Invented by Hisamoto in 1989 and developed by Hu's Berkeley group in 1999, first shipped by Intel as Tri-Gate in 2011, and the basis of every leading chip since.
- sources: https://en.wikipedia.org/wiki/Fin_field-effect_transistor
- confidence: high

## EUV lithography
- year: 2019
- kind: concept
- era: modern
- parent: integrated-circuit
- creators: none
- wikipedia: EUV lithography
- summary: Chip patterning with 13.5 nm extreme ultraviolet light, in high volume manufacturing from 2019. ASML is the only maker of the machines, which every leading 5 nm and 3 nm chip depends on.
- sources: https://en.wikipedia.org/wiki/EUV_lithography
- confidence: medium

## The Sword of Damocles
- year: 1968
- kind: device
- era: integrated
- parent: sketchpad
- creators: Ivan Sutherland
- wikipedia: Ivan Sutherland's head-mounted 3D display
- summary: Sutherland's head mounted display, hung from the ceiling on a tracking arm, and the first working augmented or virtual reality system. He called it simply the head-mounted display.
- sources: https://en.wikipedia.org/wiki/Ivan_Sutherland%27s_head-mounted_3D_display
- confidence: high

## Oculus Rift
- year: 2013
- kind: device
- era: modern
- parent: the-sword-of-damocles (queued above; if it is not added, sketchpad)
- creators: Palmer Luckey
- wikipedia: Oculus Rift
- summary: Palmer Luckey's low cost virtual reality headset, crowdfunded in 2012 and shipped to developers as DK1 in March 2013, with the consumer version following in 2016. It restarted consumer VR.
- sources: https://en.wikipedia.org/wiki/Oculus_Rift
- confidence: high
