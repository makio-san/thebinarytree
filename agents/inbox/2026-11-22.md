## Post Office Protocol (POP3)
- year: 1984
- kind: network
- era: network
- parent: email
- creators: J.K. Reynolds (RFC 918), M.T. Rose (RFC 1081, POP3)
- wikipedia: Post Office Protocol
- summary: A simple way for a mail client to download its messages from a server and then disconnect. The first version was RFC 918 in 1984, and version 3, the one still in use, followed in RFC 1081 in 1988.
- sources: https://www.rfc-editor.org/rfc/rfc918.json, https://www.rfc-editor.org/rfc/rfc1081.json, https://en.wikipedia.org/wiki/Post_Office_Protocol
- confidence: high

## MIME
- year: 1992
- kind: concept
- era: network
- parent: email
- creators: N. Borenstein, N. Freed
- wikipedia: MIME
- summary: Multipurpose Internet Mail Extensions let an email carry attachments, images and text in any character set, not just ASCII. Its content types were later borrowed by HTTP, so every web response still names its MIME type.
- sources: https://www.rfc-editor.org/rfc/rfc1341.json, https://en.wikipedia.org/wiki/MIME
- confidence: high

## Simple Network Management Protocol (SNMP)
- year: 1988
- kind: network
- era: network
- parent: tcp-ip
- creators: J.D. Case, M. Fedor, M.L. Schoffstall, J. Davin
- wikipedia: Simple Network Management Protocol
- summary: A standard way to ask routers, switches and printers how they are doing and to change their settings remotely. Published as RFC 1067 in 1988, it became the base of network monitoring.
- sources: https://www.rfc-editor.org/rfc/rfc1067.json, https://en.wikipedia.org/wiki/Simple_Network_Management_Protocol
- confidence: high

## Lightweight Directory Access Protocol (LDAP)
- year: 1993
- kind: network
- era: network
- parent: tcp-ip
- creators: W. Yeong, T. Howes, S. Kille
- wikipedia: Lightweight Directory Access Protocol
- summary: A lighter way to reach X.500 directories over TCP/IP, first published as RFC 1487 in 1993. It became the usual central store for user accounts and passwords inside organisations.
- sources: https://www.rfc-editor.org/rfc/rfc1487.json, https://en.wikipedia.org/wiki/Lightweight_Directory_Access_Protocol
- confidence: high

## Dynamic Host Configuration Protocol (DHCP)
- year: 1993
- kind: network
- era: network
- parent: tcp-ip
- creators: R. Droms
- wikipedia: Dynamic Host Configuration Protocol
- summary: Hands a device its IP address and network settings automatically when it joins a network. Published as RFC 1531 in 1993, it is why plugging in or joining Wi-Fi needs no manual setup.
- sources: https://www.rfc-editor.org/rfc/rfc1531.json, https://en.wikipedia.org/wiki/Dynamic_Host_Configuration_Protocol
- confidence: high

## Session Initiation Protocol (SIP)
- year: 1999
- kind: network
- era: network
- parent: voip
- creators: M. Handley, H. Schulzrinne, E. Schooler, J. Rosenberg
- wikipedia: Session Initiation Protocol
- summary: A text based signalling protocol, modelled on HTTP and SMTP, that sets up and ends voice and video calls over IP. Published as RFC 2543 in 1999, it now carries most internet telephony and VoLTE calls.
- sources: https://www.rfc-editor.org/rfc/rfc2543.json, https://en.wikipedia.org/wiki/Session_Initiation_Protocol
- confidence: high

## MQTT
- year: 1999
- kind: network
- era: network
- parent: tcp-ip
- creators: Andy Stanford-Clark, Arlen Nipper
- wikipedia: MQTT
- summary: A tiny publish and subscribe messaging protocol written to monitor oil pipelines over slow satellite links. It became the common language of the Internet of things and an OASIS and ISO standard.
- sources: https://mqtt.org/faq/, https://en.wikipedia.org/wiki/MQTT
- confidence: high

## YAML
- year: 2001
- kind: concept
- era: modern
- parent: json
- creators: Clark Evans, Ingy döt Net, Oren Ben-Kiki
- wikipedia: YAML
- summary: A data format that uses indentation instead of brackets, first proposed by Clark Evans in May 2001. It became the usual format for configuration files, from CI pipelines to Kubernetes.
- sources: https://en.wikipedia.org/wiki/YAML, https://yaml.org/
- confidence: high

## Protocol Buffers
- year: 2001
- kind: concept
- era: modern
- parent: json
- creators: none (Google)
- wikipedia: Protocol Buffers
- summary: Google's compact binary format for structured data, described once in a schema and compiled into code for each language. Used inside Google from early 2001 and released as open source in July 2008.
- sources: https://protobuf.dev/history/, https://en.wikipedia.org/wiki/Protocol_Buffers
- confidence: high

## gRPC
- year: 2016
- kind: component
- era: modern
- parent: http-2
- creators: none (Google)
- wikipedia: gRPC
- summary: An open source remote procedure call framework built on HTTP/2 and Protocol Buffers, grown from Google's internal Stubby. Google opened it in 2015 and version 1.0 shipped in August 2016; it is now a common way for microservices to talk.
- sources: https://grpc.io/about/, https://en.wikipedia.org/wiki/GRPC
- confidence: high

## QEMU
- year: 2003
- kind: component
- era: modern
- parent: virtualization-cloud
- creators: Fabrice Bellard
- wikipedia: QEMU
- summary: An open source emulator that runs software built for one processor on another by translating its code on the fly. Paired with KVM it became the standard virtual machine monitor on Linux.
- sources: https://en.wikipedia.org/wiki/QEMU
- confidence: high

## Word2Vec
- year: 2013
- kind: concept
- era: modern
- parent: backpropagation
- creators: Tomáš Mikolov, Kai Chen, Greg Corrado, Ilya Sutskever, Jeff Dean
- wikipedia: Word2Vec
- summary: A shallow neural network from Google that learns a vector for each word from the words around it, so that similar words land close together. It made word embeddings cheap enough to train on huge text corpora and fed straight into later language models.
- sources: https://en.wikipedia.org/wiki/Word2Vec
- confidence: high
