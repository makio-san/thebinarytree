## Apache Iceberg
- year: 2017
- kind: concept
- era: modern
- parent: parquet
- creators: Ryan Blue and Daniel Weeks
- wikipedia: Apache Iceberg
- summary: An open table format for large analytic tables, built at Netflix in 2017 to fix the limits of Apache Hive tables. It lets Spark, Trino, Flink and other engines work safely on the same tables at once.
- sources: https://en.wikipedia.org/wiki/Apache_Iceberg
- confidence: high
