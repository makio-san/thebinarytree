## OpenAI o1
- year: 2024
- kind: concept
- era: modern
- parent: llm
- creators: none (OpenAI)
- wikipedia: OpenAI o1
- summary: The first of OpenAI's reasoning models, which spend time thinking before they answer. A preview shipped in September 2024 and it made trading extra compute at answer time for better reasoning a standard technique.

- confidence: high

## Model Context Protocol
- year: 2024
- kind: concept
- era: modern
- parent: llm
- creators: David Soria Parra, Justin Spahr-Summers
- wikipedia: Model Context Protocol
- summary: An open standard from Anthropic for connecting AI models to tools and data sources through one protocol instead of a custom integration for each. OpenAI and Google DeepMind adopted it, and in December 2025 it was donated to a fund under the Linux Foundation.
- sources: https://www.anthropic.com/news/model-context-protocol, https://en.wikipedia.org/wiki/Model_Context_Protocol
- confidence: high

## Stable Diffusion
- year: 2022
- kind: concept
- era: modern
- parent: ai
- creators: none (CompVis group at LMU Munich and Runway, with Stability AI)

## El Capitan

- kind: machine
- era: modern

## LineShine
- year: 2026
- kind: machine
- era: modern
- parent: fugaku
- creators: none (National Supercomputing Center in Shenzhen)
- wikipedia: none
- summary: A Chinese system in Shenzhen that debuted at number one on the June 2026 TOP500 list at 2.198 exaflops, displacing El Capitan. Reported to be CPU only, built from ARMv9 processors, which makes it a descendant of the Fugaku approach.

## Google Willow
- year: 2024
- kind: machine
- era: modern
- parent: sycamore
- creators: none (Google Quantum AI)
- wikipedia: none found under "Willow (processor)"
- summary: A 105 qubit superconducting chip announced in December 2024 and the first to show error correction getting better as more qubits were added. Each step up in code size from 3 to 5 to 7 halved the logical error rate.
- sources: https://blog.google/technology/research/google-willow-quantum-chip/
- confidence: high

## HTTP/3 and QUIC
- year: 2022
- kind: network
- era: modern
- parent: http-2
- creators: Jim Roskind (QUIC, at Google)
- wikipedia: HTTP/3
- summary: HTTP carried over QUIC, a transport built on UDP instead of TCP. QUIC was standardised as RFC 9000 in May 2021 and HTTP/3 as RFC 9114 in June 2022, the first time the web moved off TCP.
- sources: https://www.rfc-editor.org/rfc/rfc9114.html, https://www.rfc-editor.org/rfc/rfc9000.html, https://en.wikipedia.org/wiki/HTTP/3, https://en.wikipedia.org/wiki/QUIC
- confidence: high

## WebGPU
- year: 2023
- kind: component
- era: modern
- parent: webgl
- creators: none (W3C GPU for the Web group)
- wikipedia: WebGPU
- summary: A W3C web API for the GPU built on Vulkan, Metal and Direct3D 12, intended to supersede WebGL. Chrome shipped it by default in version 113 in May 2023, opening the GPU to graphics and machine learning on the web.
- sources: https://developer.chrome.com/blog/webgpu-release, https://en.wikipedia.org/wiki/WebGPU
- confidence: high

## WebAuthn and Passkeys
- year: 2019
- kind: concept
- era: modern
- parent: public-key
- creators: none (W3C and the FIDO Alliance)
- wikipedia: WebAuthn
- summary: A W3C standard, a Recommendation since March 2019, for signing in to websites with a public key credential held by the device instead of a password. These credentials became known as passkeys.
- sources: https://www.w3.org/TR/2019/REC-webauthn-1-20190304/, https://en.wikipedia.org/wiki/WebAuthn
- confidence: high
