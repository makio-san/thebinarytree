# Tech scout, 2026-11-22 (second run)

## What I did

Today's first run (`agents/tech-scout-2026-11-22`) already exists on origin, so this run uses the `-2` names. I ran one quick news search for November 2026. It turned up only point releases (.NET 11, Windows 11 26H2, Blender 5.3, a GraphQL spec edition) and model announcements that only aggregator sites report, so none were kept. Then I grepped about 170 well known names against `src/data` to find long standing gaps. Of the zero-hit names, I queued the ones that are a lineage's next step or clearly changed how people work.

Sources: two batched Wikipedia requests (13 intros, then 13 wikitext pages, five seconds apart, no 429).

Candidates queued in `agents/inbox/2026-11-22-2.md`: 11 (APL, Forth, Kerberos, FPGA, Verilog, VHDL, NumPy, pandas, scikit-learn, Apache Parquet, SMB).

## Skipped

- HDMI, SATA, SCSI, Thunderbolt, InfiniBand, NVLink: these also wait on the "Buses and interconnects" group proposed in `2026-11-20-2.md`, like DisplayPort.
- Other zero hits (Keras, XGBoost, ONNX, vLLM, Flink, Snowflake, BigQuery, HDF5, NetCDF, CMake, Maven, RabbitMQ, ZeroMQ, Hyper-V, Matplotlib): weaker cases or not researched this run. They are candidates for a later gap sweep.

## For a human

- APL and Forth are placed under `early-languages`. Neither descends from it, so the curator may prefer the `languages` root.
- APL uses 1966 (first working system); the notation dates from 1962. Kerberos uses 1989 (first public version); MIT development started in 1986. pandas uses 2009 (open sourced); the infobox's 2008 date is marked citation needed. scikit-learn uses 2010 (first public release); the project began in 2007. VHDL uses 1987 (IEEE 1076); work began in 1983. Each summary gives both dates.
- The FPGA creators are left as Xilinx. Ross Freeman is usually credited, but the source I opened does not name him.
- Verilog, VHDL and FPGA all go under `integrated-circuit`. A small "chip design" group could hold them if the curator prefers.
